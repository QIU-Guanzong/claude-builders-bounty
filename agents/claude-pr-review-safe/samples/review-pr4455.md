### Summary

This pull request adds a Python CLI, a heuristic review formatter, and a GitHub Actions workflow that comments on pull requests. The Python implementation does not invoke Claude Code, so it cannot perform the behavior-level review described by the bounty.

### Risks

- **High** `agents/claude-pr-review/claude_review.py`: The review is based on path names, line counts, and a few regular expressions; it can miss logic defects while still reporting that no critical regressions were detected.
- **Medium** `agents/claude-pr-review/claude_review.py`: Both the `gh pr diff` process and the fallback HTTP read have no timeout or response-size limit, so a slow or unusually large diff can stall or consume excessive memory.
- **Medium** `.github/workflows/claude-pr-review.yml`: The workflow runs on every opened, synchronized, or reopened PR and passes `--post-comment`, which publishes review text without a maintainer checking it first.

### Improvement suggestions

- Invoke Claude Code in print mode with tool access disabled and validate a fixed JSON schema before rendering the comment.
- Bound the GitHub request and diff size, and reject malformed or non-canonical PR URLs.
- Keep posting manual by default; require an explicit maintainer action before a comment is sent.

**Confidence:** High
